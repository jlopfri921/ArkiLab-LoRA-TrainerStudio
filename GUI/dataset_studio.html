Dataset Studio 0.4 alpha

Organize image datasets by project. Indexed by reference: source files are never modified, moved or deleted.

Getting started

1. Select an existing image project. 2. Enter an absolute folder on this computer. 3. Import supported images (JPG, PNG, WebP, GIF or BMP), review them and remove references as needed. Subfolders and video/audio are not included yet.

This is an early development preview. Thumbnails display source images through a local-only endpoint; no image processing or AI captioning is performed.
